## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Expert input -> POST/PATCH /expert/topics | Title, description, price, icon and tags |
| /me -> editor | pricing_limits read in memory only |
| Process restore -> editor | SavedStateHandle values and the serialized nav key |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-10-29 | Tampering | Client-side floor bypass | accept | Client check is UX only; server `PRICE_BELOW_MINIMUM` is authoritative and is shown on the field |
| T-10-30 | Integrity | Stale or persisted pricing_limits | mitigate | Read `userManager.me.value` at validation time; one refresh when null; nothing persisted (grep gate) |
| T-10-31 | Tampering (input validation) | Restored SavedStateHandle text | mitigate | Restored values pass through the same caps, `filterInput` and `parse` before any request |
| T-10-32 | Denial of service | Double submit | mitigate | `isSaving` single flight; Back locked while saving (10-13) |
| T-10-33 | Elevation of privilege | Editing another expert's topic by id | accept | Server scopes PATCH by `expert_id`; ids come only from the expert's own list |
</threat_model>
