<objective>
Add the data layer for Phase 10: three stateless repositories over the new endpoints and the one-shot `TopicEvents` channel that carries a saved topic back to the Topics list.

Purpose: ViewModels in Wave 3 (Topics, Topic Editor, Edit Expertise, Availability) depend on these and nothing else from the network layer. Keeping them cache-free avoids leaking one expert's data into another session.
Output: 4 main classes, a Hilt module binding, 2 test classes.
</objective>

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-10-16 | Information disclosure | Singleton state across logout/login | mitigate | Repositories hold no state; `TopicEvents` is a `SessionDataCleaner` drained by `UserManager` on logout and login |
| T-10-17 | Elevation of privilege | Topic id in DELETE/PATCH path | accept | Server scopes by `expert_id = req.user.id` and returns a uniform 404 (T-13-05 server-side) |
| T-10-18 | Integrity | Tag ids casing | mitigate | `saveProfileTags` lower-cases ids (server lookups are case-sensitive) |
</threat_model>
