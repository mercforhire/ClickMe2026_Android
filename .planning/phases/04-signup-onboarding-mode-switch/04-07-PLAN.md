<objective>
Port `SignupAccumulator.swift` as a `@Singleton SignupSetupRepository` with a `SignupDraft` model and a `SetupStep` enum, and create the shared signup strings and a shared test harness.

Purpose: the hub, five steps and Review are separate nav entries with entry-scoped ViewModels, so they share state through this repository (RESEARCH Pattern 4; an Activity-scoped ViewModel would leak across logout, Pitfall 5). It owns the D-03 publish rules, D-04/D-25 save semantics, D-06 missing_fields mapping and D-09/D-10 hydration.
Output: the repository, draft, step enum, `strings_signup_common.xml`, `SignupTestHarness`, and tests.
</objective>
