<objective>
Build the Mode Switch page and the onboarding carousel as stateless, Robolectric-testable screens. Plan 04-18 wires them into the home shells.

Purpose: ONB-02 (port of `ModeSwitchView`, D-18/D-19) and ONB-01 (port of `OnboardingView`, D-21). Neither needs a ViewModel: the shell that pushes the Mode Switcher already knows the current mode (the route follows the mode, plan 04-06), and the carousel's only action is a finish callback. This is a deliberate simplification of the two trivial iOS view models; the onboarding page data moves to `OnboardingPages`.
Output: two screens, one card subview, page data, two strings files, two tests.
</objective>
