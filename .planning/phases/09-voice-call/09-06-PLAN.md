`@Singleton class AgoraManager @Inject constructor(@ApplicationContext private val context: Context, @IoDispatcher private val io: CoroutineDispatcher) : CallEngine`. The constructor touches no native code (CallCenter, and therefore AgoraManager, is created at app start in 09-11).
- State: `private var engine: RtcEngine?` guarded by a `Mutex`; `@Volatile private var isLeaving = false`; `@Volatile private var leaveSignal: CompletableDeferred<Unit>?`; `private val _events = MutableSharedFlow<EngineEvent>(extraBufferCapacity = 64)`; `override val events = _events.asSharedFlow()`.
- `handler: IRtcEngineEventHandler` overriding `onJoinChannelSuccess` and `onRejoinChannelSuccess` -> `LocalJoined`, `onUserJoined(uid, _)` -> `RemoteJoined(uid)`, `onUserOffline(uid, reason)` -> `mapUserOffline`, `onConnectionStateChanged(state, reason)` -> `mapConnectionStateChanged(state, reason, isLeaving)?.let(_events::tryEmit)`, `onLeaveChannel(stats)` -> `leaveSignal?.complete(Unit)`, `onError(err)` -> `Error(err)`. Callbacks only call `tryEmit` / `complete` (SDK threads; never touch other state).
- `join(token, channelName, uid)`: `withContext(io)` + mutex: create the engine if null with `RtcEngineConfig().apply { mContext = context.applicationContext; mAppId = BuildConfig.AGORA_APP_ID; mEventHandler = handler }`, then `setAudioProfile(Constants.AUDIO_PROFILE_SPEECH_STANDARD)`, `setAudioScenario(Constants.AUDIO_SCENARIO_DEFAULT)`, `setDefaultAudioRoutetoSpeakerphone(true)`, `setEnableSpeakerphone(true)`; `isLeaving = false`; `ChannelMediaOptions().apply { channelProfile = Constants.CHANNEL_PROFILE_COMMUNICATION; clientRoleType = Constants.CLIENT_ROLE_BROADCASTER; publishMicrophoneTrack = true; autoSubscribeAudio = true }`; return `rtc.joinChannel(token, channelName, uid, options) == 0`. Catch any exception from `RtcEngine.create` and return false. Do NOT enable volume indication or the spike heartbeat (spike-only evidence logging).
- `leave()`: `withContext(io)`: if no engine return; `isLeaving = true`; new `leaveSignal`; `rtc.leaveChannel()`; `withTimeoutOrNull(LEAVE_TIMEOUT_MS) { signal.await() }`.
- `setMuted(muted)` = `engine?.muteLocalAudioStream(muted) == 0`; `setSpeakerOn(on)` = `engine?.setEnableSpeakerphone(on) == 0` (iOS also resets playback volume to 100, the default; not needed).
- `destroy()`: `withContext(io)` + mutex: if an engine exists, `RtcEngine.destroy()`, `engine = null`, `isLeaving = false`. Never called from a callback (RESEARCH Pitfall 10).
- Logging: at most `Log.i(TAG, "conn state=$state reason=$reason")` and `Log.w(TAG, "error code=$err")` from callbacks, for D-16 UAT evidence. Never log token, channel name or any uid (T-09-02). The spike's companion-object state flow is not ported.
- KDoc: port of iOS AgoraManager; created only after `CallForegroundController.startAndAwait` returned true (ordering owned by CallCenter, spike finding); `onUserJoined` is expected for a peer already in the channel right after the local join (RESEARCH A5, covered by D-16 UAT).
