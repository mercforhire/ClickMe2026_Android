## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-09-43 | Spoofing | A third-party app sending MainActivity the expand extra | accept | The extra only expands an already-live call of the signed-in user (`expand()` no-ops otherwise); no data is read from the intent |
| T-09-44 | Tampering | Accidental hang-up via Back or a swipe | mitigate | Back only minimizes; only End Call / End Session / the notification action end the call (tested) |
| T-09-45 | Information disclosure | Screen reader reaching content under the call layer | mitigate | `clearAndSetSemantics` on the content while expanded; layer swallows pointer input (tested) |
| T-09-46 | Tampering | Meeting link launch | mitigate | Only through `rememberExternalMeetingLauncher` (allow-list, REQUIRE_NON_BROWSER, Custom Tab fallback; T-09-07) |
</threat_model>
