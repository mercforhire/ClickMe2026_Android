## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Backend -> app | `join_url` is set by the expert and returned verbatim by `/join` |
| App -> other apps | The meeting link leaves the app through an implicit ACTION_VIEW intent |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-09-07 | Tampering / Elevation | Malicious `join_url` launching an arbitrary component (`intent:`, `android-app:`) | mitigate | Scheme allow-list (`http(s)` with host, `skype`, `zoommtg`, `zoomus`, `msteams`); `CATEGORY_BROWSABLE`; no `Intent.parseUri`; tested rejections |
| T-09-08 | Information disclosure | `javascript:` / `file:` / `content:` URIs reading local data | mitigate | Rejected by the allow-list before any launch; Custom Tab fallback only for http(s) |
| T-09-09 | Spoofing | Provider mislabel making a phishing link look like Zoom | mitigate | iOS detect rules; unknown hosts render "Open Meeting" with the generic icon (UI in 09-09) |
| T-09-10 | Elevation of privilege | Client-side join window treated as authorization | mitigate | Rule documented as UX only; server enforces participant and window on `/join` (T-09-03) |
</threat_model>
