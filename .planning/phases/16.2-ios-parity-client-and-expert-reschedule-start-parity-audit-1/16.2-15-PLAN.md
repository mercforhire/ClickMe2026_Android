<objective>
Close the padding half of G-16.2-3 (cosmetic). The paired action buttons lose their 24 dp side padding, as on iOS, so "Reschedule" fits its half-width slot at 384 dp and "Cancel Booking" fits at 411 dp. Each fix is proved by a real-label, real-font test at the failing width.

Purpose: UAT Test 3 saw "Reschedul" / "e" on the expert upcoming card on an SM-A075F (384 dp). Diagnosis (`.planning/debug/expert-reschedule-label-wraps.md`) found the cause. The card's inner width is exactly 320 dp, so ActionButtonPair stays a Row, and each 156 dp half loses 48 dp to PressScaleButton's 24 dp side padding plus 32 dp to the glyph and spacer. That leaves 76 dp for an 84.5 dp label. iOS (`UpcomingBookingsSessionCard.swift:235-253`, `UpcomingBookingCard.swift` secondaryButton) uses no horizontal padding. The same geometry hits the client card, which plan 16.2-13 now shows on every non-pending-reschedule booking. On the two details screens, "Cancel Booking" (113.7 dp) already wraps between words at 411 dp because OutlinedButton keeps 24 dp side padding.

Output: one padding constant, two optional padding parameters with unchanged defaults, four call sites, a test helper, and NATIVE-graphics regression tests. The stacking half (stack when a label cannot fit) is plan 16.2-16; it comes after this plan so that the 411 dp rows stay rows.
</objective>
