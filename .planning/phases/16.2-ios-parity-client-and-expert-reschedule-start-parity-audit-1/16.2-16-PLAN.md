<objective>
Close the stacking half of G-16.2-3. ActionButtonPair stacks when a label cannot fit its half, not only by container width. Real-font tests at 360 and 384 dp lock all four entry points, the UI-SPEC is updated, and the full gate runs after the four gap-closure plans.

Purpose: plan 16.2-15 removed the excess padding, so the reported 384 dp case fits as on iOS. Today's stack rule only looks at the container width (stack under 320 dp) and the font scale. At 328-339 dp of content (for example the details screens on a 360 dp phone) a two-word label like "Cancel Booking" (about 162 dp with compact padding) still gets a 156 dp half and breaks between words. Any future label or translation could break mid-word the same way. The UAT gap asks for both fixes, plus a regression at 384 dp and ideally 360 dp.

Output: a rewritten two-child path in ActionButtonPair, deterministic and real-font tests, the UI-SPEC wording, and a green full gate.
</objective>
