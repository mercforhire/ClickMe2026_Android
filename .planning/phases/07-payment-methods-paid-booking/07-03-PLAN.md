<objective>
Write the Android-free core of the paid flow: the step and request model, the Stripe outcome types the Compose hosts report back, the UTC request strings, and the port of iOS `handlePaidFlowError` as a pure, table-tested function with the new copy.

Purpose: RESEARCH's key insight is that the app's job is sequencing, single flight and error mapping, all pure and testable. Putting the 15-code table (D-13), the shared slot/meeting handling (D-14), the 3DS hard failure (D-15), the unknown-outcome rule (D-16) and the My Bookings variant (D-19) in one pure function lets the ViewModel plans (07-10, 07-11) only apply side effects.
Output: `PaidBookingFlow.kt`, `PaidFlowError.kt`, `stripe/StripeOutcomes.kt`, new strings, and two test files.
</objective>
