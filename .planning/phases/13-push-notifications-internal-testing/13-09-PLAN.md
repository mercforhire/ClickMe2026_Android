<objective>
Build the Write Review state machine: load the review context, hold the rating and comment with the iOS defaults and the backend limits, switch to a read-only state for an already-submitted review, submit once, and hand the result to whichever screen opened Write Review so it can reload and say thanks.

Purpose: REV-01's logic (D-19), JVM-tested with SavedStateHandle and the 13-03 fakes; 13-13 renders it and 13-15 consumes the hand-off on Booking Summary and My Bookings. If the schedule slips, Write Review is the second cut (CONTEXT carried cut order).
Output: UI state, assisted ViewModel, `ReviewLaunchRequest`, `ReviewModule`, one string, two test classes.
</objective>
