<objective>
Register the device's FCM token with the backend on every app start and foreground return while logged in, re-register on token rotation, and unregister on logout through the existing `PushTokenRegistrar` hook.

Purpose: PUSH-01 / ROADMAP success criterion 1. Without a registered `platform: "android"` token the backend has nowhere to send Android pushes. The work fills the Phase 2 hook without changing `UserManager` or its tests (RESEARCH F-4), follows the `RealtimeConnectionManager` login-times-foreground policy, and keeps every Firebase call behind a seam so JVM tests never touch Firebase.
Output: registrar, token source seam, device-id store, registration manager, messaging service with `onNewToken`, Hilt bindings, four test files and a fake.
</objective>
