# Phase 16.4 Plan 01: Wire contract for private booking notes and the expert's client profile Summary

**Role-switched BookingNoteRepository (four note calls, NoteRole picks the endpoint), GET /expert/clients/{id} with DTOs and repository, FakeClickMeApi overrides and shared fixtures, all pinned by MockWebServer exact-wire tests.**

## Performance

- **Duration:** about 28 min
- **Tasks:** 3 (1 tracer, 2 auto, all `tdd="true"`)
- **Files:** 8 created, 4 modified

## Accomplishments

- Both private notes work at the wire: exact method, path and body per role, empty string sent as `{"note":""}`, null decoding, the uniform 404 and the server message on a save failure.
- The client profile call decodes every field and every null (including an empty `languages` array and a microsecond `member_since` with a numeric offset), and 403 `NO_RELATIONSHIP` vs 404 `NOT_FOUND` are told apart by `ErrorCode.NoRelationship` and `isNotFound()`.
- `BookingNoteData`, `BookingNoteRequest` and `ExpertClientProfileData` have redacted `toString` (note text never printed, profile prints the id only).
- `FakeClickMeApi` carries handlers, counters and recorded arguments for all five new methods, so the whole unit-test source set keeps compiling; `BookingNoteFixtures` gives later plans `bookingNoteData(...)` and `expertClientProfile(...)`.
