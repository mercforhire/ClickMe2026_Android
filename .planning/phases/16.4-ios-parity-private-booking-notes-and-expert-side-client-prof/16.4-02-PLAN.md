<objective>
Create the shared pieces both note surfaces and the Client Profile build on: the three serializable, origin-distinct navigation keys with their Hilt-free entry functions, and the one set of note composables the four cards and two summaries share.

Purpose: `NavDisplay` crashes on equal keys across stacks, so origin rules are proven at the key and shell level first. Keeping keys and composables independent of the wire layer lets every later plan compile against them in parallel. The leading tracer proves one route through the real shell with the real hidden-bar metadata and system back.
Output: 6 new route files, 1 new component file, 1 new string file, 1 new test class, 3 extended test classes.
</objective>
