## Shared Patterns

### Error mapping (`ApiException`)
**Source:** `WriteReviewViewModel.kt:130-140` plus `ApiException.isNotFound()` (`BookingErrors.kt`). **Apply to:** `BookingNoteViewModel`, `ExpertClientProfileViewModel`. Server `userMessage` first, then `login_error_network` for Network, then a generic string.

### Dialogs
**Source:** `AuthErrorDialog.kt:20-26` (`message`, `onDismiss`, `title`, `confirmLabel`). **Apply to:** the note save error. The discard prompt is a bare `AlertDialog` without a text field.

### Loading, error and refresh (Phase 15)
**Source:** `components/EmptyState.kt` (`EmptyState`, `ErrorState`, `EmptyStateAction`), skeleton composables, `RefreshFailedSnackbarEffect`. **Apply to:** the editor and Client Profile.

### Privacy
Note text is never logged, never put in a key, and never printed by `toString` (precedent `SummaryReview.Submitted.toString`).

Run `bash scripts/check-design-rules.sh` and `ktlintCheck` per plan. Strings go in new `res/values/strings_booking_note.xml` and `strings_client_profile.xml`.
