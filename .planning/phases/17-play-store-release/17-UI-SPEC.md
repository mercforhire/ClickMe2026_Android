# Phase 17 — UI Design Contract

> Phase 17 is a release phase. It adds no screens, components, copy styles or design tokens. The only UI change is the D-09 pre-release fix in plan 17-02, which corrects a layout bug on the existing call screen. This contract was written after Wave 1, at the user's choice (2026-11-06), to satisfy the `ui.safety-gate`. It records that the visual design is unchanged. It was not generated by gsd-ui-researcher.

---

## Design System

Unchanged from `15-UI-SPEC.md` and the Phase 16.x contracts:

| Property | Value |
|----------|-------|
| Tool | none (Jetpack Compose + Material 3) |
| Component library | Material 3 plus the in-house `components/` set |
| Theme | Dark only. `ClickMeTheme` in `ui/theme/` |
| Icon library | Material Icons Extended |
| Font | Nunito variable font (`NunitoFamily`), weights 400 and 600 only |

**No new colors, font sizes, weights, spacing tokens, shapes or motion specs are introduced.** `scripts/check-design-rules.sh` must keep printing "Design rules: OK".

## Contract

1. **Layout:** on the call screen, every call control stays reachable and visible above End Call at font 1.0 to 2.0 and at every display zoom on the 720x1600 Samsung SM-A075F. When content still overflows, the scroll content scrolls by touch. The BUG-10 rules are kept: End Call stays pinned and clear of the navigation bar.
2. **Avatar and glow:** same size, color, alpha and position as Phase 9/15. Phone layout unchanged (`avatarUnchangedOnPhone`).
3. **Accessibility:** touch targets stay at least 48 dp. Control labels stay visible (no truncation to icons only). `A11yAuditTest` stays green.
4. **Copy:** no string changes on the call screen.
