# Phase 16.5 Plan 04: Splash motion and accessibility Summary

The splash now plays `SplashScreenView.swift`'s motion with the same numbers, holds a static final frame when the system animator scale is 0, and reads to TalkBack as one node.

## What was built

- **Task 1 (tracer), commit 99134569:** `SplashMotion.kt` holds the D-07 constants (700 ms entrance from scale 0.82, 600 ms text fade after 350 ms, 1600 ms glow pulse over alpha 0.28 to 0.45 and scale 0.95 to 1.05, static glow alpha 0.365). `rememberSplashMotion(animationsEnabled)` drives them with `Animatable`s and an infinite transition; with animations off, or after a configuration change, every value rests on its final frame. `rememberAnimationsEnabled()` reads `ANIMATOR_DURATION_SCALE`. `SplashScreen` now delegates to `SplashContent(motion)`, where the logo group fades and scales in `graphicsLayer`, and the glow is a 190 dp box drawing a 160 dp radial-gradient circle in `drawBehind` (no blur, no render effect, colors from the theme).
- **Task 2, commit 62412aa9:** the root carries `clearAndSetSemantics { contentDescription = "ClickMe. Book time with the best minds." }` (no live region), a `SPLASH_SCREEN_TAG` for tests, and a 200% font test (wordmark one line, tagline wraps). `CallOverlayHostTest.expandedCallDrawsAboveTheSplash` pins an expanded call above the splash. `AppRoute` KDoc rewritten.

## Deviations from Plan

- **entrancePlayed timing (judgment call):** the plan says set it "when they finish". At the plan's own 800 ms restore point the text fade (ends at 950 ms) has not finished, so a finish-time flag would replay the entrance on restore. It is set when the entrance starts, and `playEntrance` is `remember`ed so the flip does not swap values mid-flight. Same observable contract as the plan's `recreationDoesNotReplayTheEntrance`.
- **Extra tests:** `animatorScaleOneKeepsAnimationsOn` and `missingAnimatorScaleKeepsAnimationsOn` split out of the plan's single `animatorScaleZeroIsReducedMotion`, because the setting is read once per composition and one activity cannot recompose with a new setting.
- **No separate RED commit:** tests and implementation were written together for each task and committed as one task commit.
- **Plan-03 tests edited:** `showsTheMarkWordmarkAndTagline` now uses `useUnmergedTree = true` since the merged tree is one node.
