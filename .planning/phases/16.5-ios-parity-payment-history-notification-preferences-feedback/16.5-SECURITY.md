## Trust Boundaries

| Boundary | Description | Data Crossing |
|----------|-------------|---------------|
| App -> REST API | Authenticated calls for the ledger, preferences and feedback | Bearer token, feedback text and email, preference rows |
| API -> app | Server text rendered in rows and dialogs | Topic and expert names, amounts, statuses, error messages |
| App -> logs and saved state | User text must not reach either | Feedback text, email, ledger rows |
| Launch intent -> splash | Push extras arrive during the hold | Push keys and ids |
| Repository docs -> people | Runbook, audit and ledger must carry no credentials | Role names, shas |
| Local build -> Play | Out of scope in this phase | None |
