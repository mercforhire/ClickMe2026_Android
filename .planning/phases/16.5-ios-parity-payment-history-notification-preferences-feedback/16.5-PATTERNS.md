### `NotificationSettingsViewModel.kt` (debounced auto-save)
**Analog:** `MAIN/screens/settings/clientprofilesettings/ClientProfileSettingsViewModel.kt` lines 118-150 (AutoSaver construction), 385-396 (`retrySave`, `flushPendingSave`, `onCleared` backstop).
```kotlin
private val saver = AutoSaver(
    scope = viewModelScope, flushScope = appScope,   // appScope: @ApplicationScope CoroutineScope
    baseline = EmptySnapshot,
    persist = { old, new -> persist(old, new) },
    onFailure = ::onSaveFailed,
)
```
