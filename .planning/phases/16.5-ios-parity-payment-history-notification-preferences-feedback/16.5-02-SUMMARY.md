# Phase 16.5 Plan 02: Join window and Profile-stack booking route Summary

Upcoming Booking Details now fails closed for every status Payment History can open it with, and a booking opened from the Profile tab has its own key and leaves nothing parked when cancelled.

## What was built

**Task 1 (tracer), commit 49261d14.**
- `isWithinJoinWindow` is now an allow-list: only `confirmed`, `in_progress` and `pending_reschedule` use the live window, `completed` stays joinable until its end, and every other status (cancelled, declined, missed, expired, pending_approval, unknown, empty) returns false. KDoc records that `POST /bookings/:id/join` never checks status.
- New `showsJoinCard(status, end, now)`; `UpcomingBookingScreen.LoadedBody` renders `UpcomingBookingJoinCard` only when it is true, and the `md` spacer before the block renders only when the pending banner, the resume note or the card renders, so a terminal booking has one gap before Message.
- Tracer gate: the full verify command (JoinWindowTest plus upcomingbooking, mybookings, explore, expert dashboard, bookingsummary and upcomingbookings test packages, plus ktlintCheck) passed end to end before Task 2 started. Other `isWithinJoinWindow` surfaces are behaviour-neutral.

**Task 2, commit 9ca3cb46.**
- `Navigator.openUpcomingBookingFromProfile(bookingId)` pushes `UpcomingBookingKey(bookingId, StackOrigin.Profile)`.
- `Navigator.showMyBookingsAfterCancel(key)` calls `resetProfileStackHolding(key)` then `showMyBookings()`; the cancel entry now uses it.
- `resetProfileStackHolding` widened from a private `RequestSentKey` helper to `internal` and any `NavKey`; Request Sent callers unchanged.

- `HomeShellsTest`: `cancelledFromTheProfileStackReturnsTheProfileTabToItsRoot`, `cancelFromBookingsLeavesAnOpenProfileStackAlone`, `sameBookingOnExploreAndProfileDoesNotCollide`. `setClientWithBookingManagement` gained a `withProfileBookings` parameter and a captured shell navigator, because the booking screens hide the bottom bar and tests must switch tabs through `onTabSelected`.
