<objective>
Build the expert navigation skeleton for Phase 11: the two tab-root slots on the expert shell, every new route key, the origin values, the cross-tab Navigator helpers, the one-shot hand-off store, and one entry-registration function per feature package that HomeExpertScreen calls.

Purpose: Phase 11 has seven surfaces that later plans build in parallel. If each of them added its route to `HomeExpertScreen.kt`, they would all collide on that one file and run one after another. Instead this plan wires the shell once: each feature package owns a registration function (and the two tab roots own a route composable) that HomeExpertScreen already calls, so every later plan registers and reaches its own screen in the running app by editing only its own package. The keys live here because features navigate to each other (Incoming Requests opens Request Decision; Request Decision replaces itself with Confirmed; the Dashboard opens the Summary).
Output: shell slots and seven route/registration files, five key files, the origin enums, `ExpertNavigation.kt`, `ExpertLaunchRequest.kt`, and three tests.
</objective>
