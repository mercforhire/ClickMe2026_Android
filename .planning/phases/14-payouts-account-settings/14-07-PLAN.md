<objective>
Build the client Profile Settings screen with iOS-style auto-save: a debounced PATCH on every change, a status icon in the app bar, an error dialog and a flush on Back, for the text fields and the professional card.

Purpose: PROF-02 (edit profile), CONTEXT D-10..D-12. The auto-save engine and the shared field composables are built here once; the avatar, languages and country editors come in 14-12 and the expert screen in 14-13 reuses all of it. Two iOS bugs are not copied: the pending debounce is flushed on leave, and the patch builder already sends languages (RESEARCH Anti-Patterns).
Output: auto-saver, snapshot and patch builder, repository, key, view model, screen, shared fields, strings and three test classes.
</objective>
