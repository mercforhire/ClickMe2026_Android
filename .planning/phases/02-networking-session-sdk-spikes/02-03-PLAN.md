<objective>
Port the error half of the networking core and the auth-path table: the 65-case `ErrorCode`, a lenient error envelope DTO, a sealed `ApiException`, an `ApiErrorParser` that turns any `Throwable` from Retrofit/OkHttp into an `ApiException`, an `apiCall { }` wrapper, and `ApiRequestUrls` (path constants plus `needAuthToken`).

Purpose: FND-04 and the `needAuthToken` part of FND-05. The transport plan (02-06) uses `ApiRequestUrls`, `ErrorCode.isTokenError` and `ApiErrorParser.codeOf`; the session plan (02-11) and the login screen (02-13) use `apiCall` and `ApiException.userMessage`. This plan has no dependency on plan 02-02 (it builds its own Moshi for the envelope), so both run in parallel.
Output: six main-source files, two test classes.
</objective>
