<objective>
Build the Search tab's data contract: the `GET /experts/search` endpoint, its DTOs, a stateless `SearchRepository`, the FakeClickMeApi handler, the shared test fixtures, and the UI-state types plus the DTO-to-UI mapper that the ViewModel (16.1-03) and the screen (16.1-04, 16.1-05) both consume.

Purpose: the backend schema is `.strict()`, so an extra or misspelled query parameter fails every search. The leading tracer proves the one endpoint end to end (URL constant, Retrofit method, DTO, repository, MockWebServer wire test) before anything is built on it. The second task pins the iOS `map()` fallbacks (D-05) and the first-visit state (D-01) in one shared file, so the ViewModel and the composables can be built in parallel in wave 2 without inventing their own types.
Output: 3 new main files, 2 modified network files, the fake override, a fixture file, 2 new test classes and an extended URL test.
</objective>
