## Shared Patterns

**Source:** `components/RefreshFailedSnackbar.kt` lines 48-64 (`RefreshFailedSnackbarEffect`) plus ViewModel `onRefreshFailureConsumed() { update { copy(refreshFailed = false) } }` (Explore VM ~line 105).
**Apply to:** Search screen and ViewModel (D-09).

### Error state
**Source:** `components/EmptyState.kt:92` `ErrorState(...)`; message from `ApiException.Http.userMessage` else `R.string.error_state_body`.
**Apply to:** Search results area (D-08).

### Skeleton loading
**Source:** `ExploreExpertsSection.kt` lines 44-62 (`SkeletonGroup` + `SkeletonBlock`).
**Apply to:** Search Loading state (3 cards).

### Theme tokens instead of iOS RGB
**Source:** `ExpertCard.kt` lines 53-54 (`MaterialTheme.colorScheme.surfaceContainerLow/outlineVariant/onSurface`, `MaterialTheme.extras.onSurfaceMuted`, `Spacing.*`, `contentMaxWidth()`).
**Apply to:** All Search composables. Only the avatar fallback green is an explicit color (via new `fallbackColor`).

### Accessibility
**Source:** `ExpertCard.kt` lines 55-77 (merged `contentDescription` + `Role.Button`), `ErrorState` polite live region.
**Apply to:** cards, chips (selected state), sort row.

### Per-tab stack / tab switch
**Source:** `navigation/Navigator.kt` `navigate(tab)` (tab switch with no reset) and `resetAndSelect` (lines 103-115).
**Apply to:** "See all" = `navigator.navigate(SearchRoot)`; re-tap = existing `reselect` (no code).
