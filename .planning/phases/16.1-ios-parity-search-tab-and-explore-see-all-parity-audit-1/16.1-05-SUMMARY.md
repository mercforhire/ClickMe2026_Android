## Deviations from Plan

### Auto-fixed Issues

**1. [Rule 1 - Bug] Typed search field had no accessible name**
- **Found during:** Task 1 (`searchFieldPassesTheA11yAudit`)
- **Issue:** Once text is typed the placeholder disappears, leaving an editable node with no name (the audit and TalkBack both see an unnamed field).
- **Fix:** while `query` is non-empty the field sets `contentDescription` to the placeholder string. Never the value, matching the `ValidatedField` convention.
- **Files modified:** `SearchExpertSearchBar.kt`
- **Commit:** d3784925

**2. [Rule 3 - Blocking] IME-Search focus test needs a second focusable**
- **Found during:** Task 1 (`imeSearchHidesTheKeyboard`)
- **Issue:** `onSearch` runs and calls `clearFocus()` (confirmed with a temporary print, since removed), but when the field is the only focusable in the test window Compose hands the focus straight back, so `assertIsNotFocused` failed. Not a product bug: the real tab has other focusables.
- **Fix:** the test host adds a `Button` next to the field. The assertion is still meaningful: the field is focused before the IME action and not after, and the test fails if `onSearch` does nothing.
- **Files modified:** `SearchExpertControlsTest.kt`
- **Commit:** d3784925

**3. [Rule 3 - Blocking] ktlint property-naming**
- **Found during:** Task 1
- **Issue:** `private const val RestingBorderAlpha` violates the screaming-snake-case rule.
- **Fix:** renamed to `RESTING_BORDER_ALPHA`.
- **Files modified:** `SearchExpertSearchBar.kt`
- **Commit:** d3784925
