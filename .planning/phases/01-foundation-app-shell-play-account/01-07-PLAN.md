## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| URLs (backend data, policy links, later Stripe/join URLs) → openCustomTab | Untrusted strings become intents that leave the app |
| Remote image URLs → Coil | Backend-provided avatar URLs are fetched over the network |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-01-20 | Tampering / Elevation of privilege | openCustomTab URI handling | mitigate | isAllowedCustomTabUri admits only https/http with a non-blank host and is checked before any startActivity; javascript:, file:, content:, intent:, mailto: are rejected and reported via onFailure (CustomTabLauncherTest); the ACTION_VIEW fallback reuses the same validated Uri with CATEGORY_BROWSABLE |
| T-01-21 | Information disclosure | Avatar remote loads | accept | Coil fetches backend-provided URLs without auth headers in Phase 1; cleartext HTTP is blocked by the platform default for targetSdk 37 |
| T-01-22 | Denial of service | Avatar image decode | accept | Coil downsamples to the requested 32-96 dp size; no unbounded decode |
</threat_model>
