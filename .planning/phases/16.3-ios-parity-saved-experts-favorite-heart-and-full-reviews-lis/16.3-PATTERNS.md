## Shared Patterns

### Error handling (`ApiException`)
Repositories throw only `ApiException` via `apiCall { }`; VMs `catch (e: ApiException)`. First-load errors: `e.toSectionMessage()` (`makeabooking/BookingErrors.kt:67`). Snackbar errors: `e.userMessage` with a string-resource fallback.

### Load modes + refresh failure UI
Source: `MyBookingsViewModel.startLoad` L140-168 and `RefreshFailedSnackbarEffect` (`components/RefreshFailedSnackbar.kt`). Apply to Favorites and ExpertReviews VMs/screens.

### Duplicate Nav3 content keys
Source: `StackOrigin.kt` KDoc. Apply to every new key/profile key created from the Profile tab: use `StackOrigin.Profile`; `ExpertReviewsKey.origin = ExpertProfileKey.origin`.

### Design rules
`scripts/check-design-rules.sh` fails on hex literals, raw `fontSize`, unused Scaffold padding. ktlint max line 120. Plain `Text` only for server text.

### Test scaffolding
`MainDispatcherRule` + `FakeClickMeApi` for VM tests; `createComposeRule` for stateless screens (Robolectric). Existing tests to update (RESEARCH Pitfall 3): `ExpertProfileScreenTest` (~L231-252, ~L375-386, ~L578), `ExpertProfileViewModelTest.vm()` L47, `ClientProfileHomeScreenTest` ~L45, `HomeShellsTest` (`clientHubRowsNavigate`, `clientHubStandIns`), `SearchNavigationTest.stackOriginAppendsSearchLast`.
