| T-03-39 | Tampering | Double-tap pushing duplicate recovery screens | mitigate | `open*` is a no-op when the same key type is on top |
| T-03-40 | Information disclosure | ViewModel state shared across pushes | mitigate | Entry-scoped ViewModels (fresh per push, tested); cross-screen data only via NavKey arguments |
</threat_model>
