## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-03-13 | Information disclosure | Password in the saved-state Bundle | mitigate | Only the email is mirrored to SavedStateHandle; the password stays in ViewModel memory (orchestrator resolution 2); acceptance grep checks no password key |
| T-03-14 | Information disclosure | Account enumeration via login errors | accept | Backend returns one generic 401 message for wrong email or password; shown verbatim under the password field |
| T-03-15 | Denial of service | Double submit / login rate limit (10 per 15 min) | mitigate | isSubmitting guard plus AsyncSaveButton ignores taps unless Idle; 429 message reaches the dialog unchanged |
| T-03-16 | Spoofing | Suspended account login | mitigate | ACCOUNT_SUSPENDED produces no local error so the existing global trap and SuspendedAccountDialog own the flow (Phase 2 D-08); test covers it |
</threat_model>
