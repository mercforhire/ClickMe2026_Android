## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| User input -> POST /auth/password/forgot | Unauthenticated request with an email |
| Server response -> UI copy | What the user learns about account existence |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-03-17 | Information disclosure | Account enumeration through forgot | mitigate | Success copy ("Code Sent!", info text) never states the account exists; the server returns 200 for any well-formed email |
| T-03-18 | Denial of service | OTP request flooding (server limit 5 per 15 min per IP) | mitigate | No resend button or cooldown loop (D-09); send ignored unless Idle; the 429 message is shown as is |
| T-03-19 | Information disclosure | Email in saved state | accept | The email is not a secret and is needed to restore the form after process death; no password or code on this screen |
</threat_model>
