## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-03-05 | Tampering | Client-side validation | accept | Validators are UX only; the server re-validates every field and stays authoritative (ASVS V5) |
| T-03-06 | Information disclosure | Server message shown in dialog | mitigate | `toDialogError` shows only `ApiException.Http.userMessage` (server `message` or first field message, never the raw body or code); ApiException's own message carries only status and code (Phase 2 T-02-08) |
| T-03-07 | Spoofing | Password autofill | mitigate | `contentType` defaults to `ContentType.Password` for secure fields so password managers fill the right field; OTP uses `SmsOtpCode` (plan 03-06) |
</threat_model>
