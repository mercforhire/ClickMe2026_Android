## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| App -> Socket.IO server (wss) | The JWT crosses in the CONNECT packet; events come back from the server |
| Socket listener thread -> app process | Untrusted payloads are handled on the library's EventThread |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-03-26 | Information disclosure | Token in URL/query or access logs | mitigate | Token only in `IO.Options.auth` (CONNECT packet inside TLS); test asserts the upgrade query has no token; grep forbids a `query =` assignment |
| T-03-27 | Information disclosure | Bearer header on the websocket upgrade | mitigate | Uses the `@Named("bare")` client (no AuthHeaderInterceptor/Authenticator); test asserts no Authorization header on the upgrade |
| T-03-28 | Denial of service | Malformed or hostile payload crashing the process | mitigate | Catch-all in every listener, decoder never throws, non-objects dropped; crash-safety test with an uncaught-exception recorder |
| T-03-29 | Information disclosure | Payloads or tokens in Logcat | mitigate | Logs contain only event names and exception class names; library JUL logging stays at default (FINE off) |
| T-03-30 | Information disclosure / Elevation | Stale socket delivering events after a token or user change | mitigate | `off()` + `disconnect()` + generation guard + `forceNew` per connection; token-swap test asserts the old socket's frames are ignored |
| T-03-31 | Denial of service | Unbounded buffering under event bursts | mitigate | `extraBufferCapacity = 64` with DROP_OLDEST; `tryEmit` never blocks the EventThread |
</threat_model>
