## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| User input -> POST /auth/password/reset | Unauthenticated request carrying email, OTP and the new password |
| ViewModel state -> saved instance state | What survives process death |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-03-20 | Information disclosure | New password in the saved-state Bundle | mitigate | Only the code is mirrored to SavedStateHandle; both password fields stay in ViewModel memory (orchestrator resolution 2); grep acceptance |
| T-03-21 | Spoofing | OTP brute force | mitigate | Server enforces 5 attempts per code, 15 min expiry and per-IP limits; client shows one generic 400 message for every failure kind (oracle-free) and offers no resend loop (D-09) |
| T-03-22 | Information disclosure | OTP or password in logs | mitigate | No logging in these files; debug HTTP logging is BASIC (no bodies) |
| T-03-23 | Tampering | Weak passwords | accept | Client rules mirror the server (8+, digit, symbol) for UX; the server's 422 is authoritative and mapped inline |
</threat_model>
