## Cross-Phase Integration

All five E2E flows that can be built today are wired end to end. The checker traced each one through the code:

1. **Cold launch:** `MainActivity` holds the splash, then `AppViewModel.resolveInitialRoute` runs `UserManager.restore()` with a 5 s cap and picks the AppRoute. The suspended path shows `SuspendedAccountDialog`. The offline path goes to `Home(currentMode)` and retries `/me` on foreground.
2. **Login:** `LoginViewModel` → `UserManager.login` → `resolvePostAuthDestination` → `AppViewModel.onLoggedIn`. The socket connects through `RealtimeConnectionManager` (`isLoggedIn` × foreground).
3. **Refresh and logout:** when `TokenAuthenticator` refreshes, it emits `Refreshed` and the socket reconnects with the new token. When a refresh fails, it emits `Rejected`, which logs the user out, routes to Login and disconnects the socket.
4. **Logout:** the client Profile, the expert Profile and the signup hub overflow all call `userManager.logout()`, which clears tokens, the store, the profile, the onboarding flag, `setupDeferred` and the photo working files.
5. **Signup → Publish → carousel → Expert mode → relaunch:** each step is wired, and the persisted mode is reloaded on restore.
